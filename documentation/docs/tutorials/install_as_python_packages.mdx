# Run OPAL as Python packages / CLI utilities

## CLI execution

Python **3.14** is required for `opal-server`, `opal-client` and `opal-common`. Note that on an older Python, such as 3.13, `pip install` of any of the three packages does not fail: pip silently picks the newest release whose metadata admits that Python, an old 0.9 release, so use 3.14.

### Server

- install
  ```sh
  pip install opal-server
  ```
- run
  ```sh
  # get CLI help
  opal-server --help
  # run server as daemon
  opal-server run
  ```

### Client

- install
  ```
  pip install opal-client
  ```
- run
  ```sh
  # get CLI help
  opal-client --help
  # run the client as a daemon
  opal-client run
  ```
