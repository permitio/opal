# Run OPAL as Python packages / CLI utilities

## CLI execution

Python **3.10 to 3.13** is required for `opal-client` (and `opal-common`). `opal-server` requires **3.10 to 3.12**: its pinned `pygit2` ships no Python 3.13 wheel yet. Note that on Python 3.13 `pip install opal-server` does not fail - pip silently picks the newest release whose metadata admits 3.13, which is the old 0.9.6 - so run the server on 3.12 or lower.

### Server

- install
  ```sh
  pip install opal-server
  ```
- run
  ```sh
  # get CLI help
  opal-server --help
  # run server as daemon
  opal-server run
  ```

### Client

- install
  ```
  pip install opal-client
  ```
- run
  ```sh
  # get CLI help
  opal-client --help
  # run the client as a daemon
  opal-client run
  ```
