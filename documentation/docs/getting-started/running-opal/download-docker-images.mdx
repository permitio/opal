The images are built on [Wolfi](https://github.com/wolfi-dev/os), with Python 3.14 in a venv at
`/opt/venv`, and run as the user `opal` (uid and gid 1000, home `/opal`). An image built `FROM`
them adds OS packages with `apk` and Python packages with `pip install --user`. From 0.10.0 on,
no `-alpine` tags are published and the default tags are no longer built on Debian; 0.9.x and
the 0.10.0 release candidates keep both.

From 0.10.0 on, the latest release's images are rebuilt every week with the Wolfi packages
published since, so OS fixes reach its tags: `<version>` and `latest` move to the rebuild, and
`<version>-<YYYYMMDD>` keeps each one. Only the OS packages change; the Python packages and OPAL's
code stay as released. 0.9.x images are not rebuilt.
